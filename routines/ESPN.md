# ESPN public sports-status ingestion

Reed deprecated general sports-data scraping from Underdog, X/Twitter and browser news sources. GitHub Actions runs scripts/fetch-espn-status.mjs (JavaScript, Node.js) each maintenance pass, with no API key or AI calls. The actual JSON base is https://site.api.espn.com/apis/site/v2/sports/, not the espn.com display-page URL. ESPN's endpoints are undocumented public services; no speed or availability guarantee.

Footprint: NFL, CFB/FBS, NBA, WNBA, CBB, WCBB, MLB, NHL; all configured soccer competitions; ATP/WTA tennis; PGA/LPGA/DP World golf. Query today and tomorrow using Chicago date and the adjacent UTC date. Store normalized public JSON in data/espn/<league>-<date>.json and freshness/error/coverage manifest in data/espn/index.json. Raw source JSON stays in ignored .cache/espn for diagnostics. Four workers, 15-second request timeout, at most 32 detail queries for current/next-24-hour team fixtures per pass. Deferred details have no checked timestamp and remain unverified. Empty event lists are legitimate, not fabricated coverage. Failed boards retain the previous successful snapshot with its old timestamp; manifest marks failure. All-board failure stops publication.

Summary parser stores ESPN injury designations, explicit starter=true roster/boxscore athletes, NHL goalies only when explicitly marked starting at position G, and competitor probables with confirmed=false. Stat leaders, depth charts and absence from injury lists never prove a start or healthy status. Hockey forward/defense line combinations remain unavailable; no inferred lines. Published sportsbook spread/total records retain their provider, separate from hockey lineup lines, and do not become independent fair probabilities. Tennis/golf have no team starter lineup; only real score/status/participant data is recorded. Unsupported/missing fields remain unverified.

Lineup/scratch routines consume fresh central detail snapshots (20-minute maximum) to update affected named picks. No extra X/Underdog/Faceoff/Bovada request or model call. Injury concerns take precedence over starter flags. Existing notes are not cleared based on missing evidence. The score/progress system continues its existing direct ESPN reads; this status database adds shared source-backed availability data.

Fade Trent is the explicitly authorized exception: Reed retained its two-hour Codex browser post check. It still consumes AI usage and cannot be fed by ESPN. It has not been migrated to GitHub Actions.
